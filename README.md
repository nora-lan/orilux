# 曜境 YAOJING · 企业科技官网

React + TypeScript + Vite 企业官网，围绕云计算、人工智能、数据与行业方案组织内容。

## 运行

```sh
npm install
npm run dev
```

## 构建与预览

```sh
npm run db:generate # 仅在修改数据库 schema 后执行
npm run build
npm run db:migrate:local # 本地初始化/应用待执行迁移
npm run preview
```

## 功能

- 产品分类筛选、关键词搜索与产品详情弹窗。
- 四类行业解决方案切换。
- 三组首屏主题轮播，可手动切换或暂停；云技术图形支持指针交互和产品直达。
- 首屏蓝色立体 SVG 默认平放，鼠标进入整个 banner 后立起并保持朝向，进行 4 秒一轮、8px 幅度的上下浮动；保留立起位置下移 28px，移出后恢复平放。触屏轻触或键盘 Enter / Space 可切换预览，失焦复位。浮动离屏或后台暂停，并响应全局动效与系统减少动画设置。导航、页脚和网站图标共用用户提供的轮廓，下方按钮独立切换立体 / 轮廓 / 流光。
- AI 生产力板块：创作类型与灵感预览、应用代码/原型切换、助手任务示例，以及与业务咨询的连接。场景素材与交互均为演示，不调用真实模型或部署应用。
- AI 创作与 Code 应用开发卡片接入用户指定的京东云演示动画，各自独立支持播放/暂停、重播和体验切换；仅在可见时播放，响应全局动效开关，减少动态效果时展示对应静态封面。
- 滚动渐入、阅读进度、导航定位、卡片悬停、方案切换动效。
- 技术资源文章阅读。
- 社区动态独立页面 `/community/`，导航和页脚直达，首页不再展示社区板块；旧 `/#community` 链接兼容跳转。支持分类筛选和此浏览器内的收藏；标题、封面和“阅读全文”在新标签页打开独立文章页面，原有演示内容保留标注。
- “曜境日常”首篇文章《聚力同行，共赴热爱｜走进曜境科技》配用户提供的文化墙原图；原有示例动态保留独立标注。
- 文章详情 `/community/article/?id=文章ID`：完整正文、照片、目录、收藏和相关阅读。
- 搜索入口后的头像进入独立个人中心 `/account/`：可编辑昵称、简介与头像配色，查看/取消收藏、分页查看本人评论、跳转原文及删除本人评论。
- 个人资料与收藏保存在当前浏览器，导航头像即时同步且支持跨标签页更新；文章评论表单默认使用个人资料中的昵称。个人中心不包含跨设备账号登录。
- 文章评论使用网站数据库共享保存，支持昵称发言、分页阅读和当前浏览器删除本人评论；服务端检查输入、同源请求和提交频率，不依赖 localStorage 保存评论。
- 业务咨询表单校验、本地需求清单生成与文本下载。
- 响应式导航、原生 dialog、键盘关闭、页面动效开关与系统减少动画支持；轮播在离屏或后台时暂停。

咨询信息仅在当前页面内处理，不发送至服务端。产品能力及运行指标为展示内容，须替换为实际业务资料后用于正式业务。

## 文件

- src/App.tsx：页面结构、产品和方案数据、交互。
- src/App.css：响应式视觉样式与云技术主视觉。
- src/HeroExperience.tsx：交互式首屏与主题轮播。
- src/usePageMotion.ts、src/motion.css：页面动效、滚动状态与减少动画控制。
- src/icons.tsx：轻量 SVG 图标。
- src/ProductShowcase.tsx：创作与应用开发演示共用的媒体加载、独立播放状态与体验切换。
- public/media/SOURCES.txt：用户指定动画及封面的原始来源；原媒体中的品牌信息保留。

设计参考火山引擎、阿里云等企业云官网的产品导航和内容层级，保留曜境独立品牌与视觉。字体不可用时自动回退至系统字体。

## 评论服务

前端输出到 `dist/client`，Worker 输出到 `dist/server`，发布时由 Sites 配置 D1 `DB` 并应用 `drizzle` 中的迁移。生产与本地数据库完全分离。

`npm run preview` 在 127.0.0.1:5173 运行完整服务；`npm run dev` 仅供前端开发，评论联调使用完整预览。接口测试：`node tests/comments-api.mjs`，仅允许 localhost，测试评论自动清理。

访客使用昵称参与，HttpOnly 浏览器会话识别本人评论；评论公开可见。昵称最多24字、正文最多1000字，服务端限制提交频率并支持幂等重试。无需把本地 `.wrangler` 或 `.sites-runtime` 数据发布。

`GET /api/comments/mine` 按当前 HttpOnly 会话筛选本人评论，支持游标分页；不接受客户端指定所有者。保留原会话 Cookie 路径以继续识别已有评论，`comments_owner_created` 索引加速个人中心查询。清除浏览器网站数据后，个人资料与收藏会重置，也无法再通过原会话管理旧评论。
