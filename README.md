# 曜境 YAOJING · 企业科技官网

React + TypeScript + Vite + ECharts 企业官网，围绕云计算、人工智能、数据与行业方案组织内容。

## 运行

```sh
npm install
npm run dev
```

## 构建与预览

```sh
npm run build
npm run preview
```

## 功能

- 产品分类筛选、关键词搜索与产品详情弹窗。
- 四类行业解决方案切换。
- ECharts 响应时间与请求吞吐量趋势图。
- 技术资源文章阅读。
- 业务咨询表单校验、本地需求清单生成与文本下载。
- 响应式导航、原生 dialog、键盘关闭与减少动画支持。

咨询信息仅在当前页面内处理，不发送至服务端。产品能力及运行指标为展示内容，须替换为实际业务资料后用于正式业务。

## 文件

- src/App.tsx：页面结构、产品和方案数据、交互。
- src/App.css：响应式视觉样式与云技术主视觉。
- src/CloudChart.tsx：模块化 ECharts 图表。
- src/icons.tsx：轻量 SVG 图标。

设计参考火山引擎、阿里云等企业云官网的产品导航和内容层级，保留曜境独立品牌与视觉。字体不可用时自动回退至系统字体。
